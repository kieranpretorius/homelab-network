# VLAN example
An example code is this one I learnt today: "ip -br addr". This gives a short list of network interfaces (learn what network interfaces are, not just surface level) and IP addresses.

# ip -br link
`ip -br link` = each interface + UP/DOWN + MAC in 1 line (no IPs). Use it to check a VLAN interface is UP.
